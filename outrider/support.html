Raptor Run Support

Help for Raptor Run, the mobile action game developed by Tappy Games under the project name Outrider.

Need help?

Tell us your iPhone model, iOS version, and what happened. Please do not send passwords or other sensitive information.

Email Raptor Run Support

Requirements

  • iPhone running iOS 16.0 or later
  • Enough free storage to install and update the game
  • No account or internet connection is required for normal play

If the game will not start

  1. Close Raptor Run and open it again.
  2. Restart your iPhone.
  3. Install the latest compatible iOS update.
  4. If needed, reinstall the game. Reinstalling may remove locally saved progress.

Controls and haptics

Raptor Run uses touch controls. Open the in-game menu and choose Options to replay the controls tutorial, switch movement mode, adjust graphics and audio, or turn haptics on and off.

Progress and privacy

Progress and settings are stored locally on the device. Raptor Run does not require Game Center or an account. See the Raptor Run Privacy Policy for details.

Purchases

The current version of Raptor Run does not contain in-app purchases.
